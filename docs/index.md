# vita 的技术文档

这里是我的个人课程文档站，主要用来记录开源软件课上折腾 MkDocs 和 GitHub Actions 自动部署的过程。

平时写长文和日常随笔一般还是放在我的主站 [维他茶馆 (vita.do)](https://vita.do) 上。这边这个站点相对轻量化一些，纯粹用本地 Markdown 写完推上 GitHub，靠工作流自动构建并托管到 GitHub Pages，算是体验一下无后端的静态文档维护流程吧。
